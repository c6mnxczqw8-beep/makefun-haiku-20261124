# Seventeen Syllables of Debugging

A make.fun entry: a Python program (`main.py`, standard library only) that
writes one haiku about debugging to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`).

The haiku — 5-7-5, exactly seventeen syllables:

> breakpoint holds its breath (5)
> the log scrolls by, still lying (7)
> the last print names me (5)

A breakpoint waits, tense and silent. The log scrolls past and lies about
what happened. Then one last printf confession tells the truth: the bug
was the author all along.

Run it:

```sh
python3 main.py            # writes /output/entry.txt
cat /output/entry.txt
```
